Whitepaper v1 · 2026-09-12 · 💯Epic Tech AI🔥™️ · Not a token sale · Not Harness, Super App, Crew, AIgent, Bot OS, or Railway Epic OS

1. Problem

Most “AI studios” either wrap someone else’s dashboard or hide the keys in the server and bill you twice. Creators need a graph they own, media that is actually the media (stills, video+audio, voice, music), a stitch to a final, and a way for other agents to see the surface without scraping a login wall.

2. Product

Chamber is a capability atelier. Make flows drop generators. Cyan OUT wires to magenta IN. Libraries keep timestamped takes. Stitch muxes picture and sound. ChamberAgent is a Durable Object on Cloudflare Workers AI (GLM + Flux by default).

2b. Per-user SOTA db

After email + code, each inbox gets its own Cloudflare Durable Object SQLite database (graphs, library index, job log, credits). Media blobs stay on the device. BYOK keys never go in that db.

3. Trust model

BYOK or pay: paste a vendor key and that job is on your bill. No key means sign-in plus Chamber credits ($0.99 = 10; Still/Voice/Music 1, Motion 3, Stitch 2, Pack 5). Keys never sit in the user db. Credits are a meter, not a withdrawable balance. Email + code opens the db. Stripe Checkout is the only card path.

4. Ecosystem

Other agents should read /llms.txt, /.well-known/agent.json, and GET /api/v1/health. Caps are listed at /api/v1/caps. Protocol 1. No iframe of sibling Epic products.

5. Economics

Platform quotas on Workers AI are real. Long video is reels, not a silent 480-minute lie. Hosted jobs without BYOK debit the user db. BYOK spend never hits Epic Tech’s vendor bill. Other agents should send x-epic-key (or sit behind a signed-in cookie with credits) or they get 402.

6. Brand

Cyan #00f3ff, magenta #ff00aa, black #0a0a0a, 💯Epic Tech AI🔥™️ on every public page. Chamber is a separate product with its own Worker and host.
